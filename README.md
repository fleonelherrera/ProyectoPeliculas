# API de Peliculas - ASP .NET Core

Aplicación web desarrollada con **ASP.NET Core 8** que consiste en una API REST para la gestión de películas alojadas en una base de datos en SQL Server.
Incluye funcionalidades básicas de ABM (Alta, Baja, Modificación) y validaciones. También desarrollé un pequeño Frontend en React como complemento visual.

## Tecnologías usadas:

- ASP.NET Core 8
- C#
- Entity Framework
- SQL Server
- React (FE)
- Bootstrap

## Objetivo:

Este proyecto fue realizado con la finalidad de aplicar conocimientos de Desarrollo Backend con .NET, manejo de base de datos y exposición de servicios RESTful.
